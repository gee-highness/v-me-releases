Install help

The apps are not signed with a store certificate yet, so your device may ask you to confirm once.

🤖 Android
  1. Download the .apk.
  2. Open it. If asked, allow your browser or file manager to "install unknown apps".
  3. Tap Install, then Open.
🪟 Windows
  1. Download the installer (setup.exe), the portable file to run without installing, or the zip (unzip, then run V-Me.exe).
  2. If SmartScreen appears: More info → Run anyway.
🐧 Linux

Any distro: download the .AppImage, then chmod +x V-Me-*.AppImage and run it.
Ubuntu/Debian: sudo apt install ./V-Me-*.deb
Fedora: sudo dnf install ./V-Me-*.rpm
Arch: sudo pacman -U V-Me-*.pacman

🍎 macOS
  1. Download the .dmg and drag V-Me to Applications.
  2. The first time, right-click V-Me → Open → Open.
